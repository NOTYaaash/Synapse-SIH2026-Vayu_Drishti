# Screenshots

This directory contains screenshots of the Vayu Drishti frontend, including the Live Map dashboard, 24-hour timeline player, and the "Your Area" hyper-local threat mapping UI.

## Naming Convention
Please ensure screenshot files are named clearly to represent their content, for example:
- `live_map_dashboard.png`
- `your_area_threat_card.jpg`
- `mobile_responsive_view.png`
